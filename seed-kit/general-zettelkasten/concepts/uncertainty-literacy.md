# Uncertainty Literacy

Varol's practical posture: the learned capacity to treat ambiguity as *signal* rather than *noise*. The uncertainty-literate observer notices when an answer is too clean, when a prediction is too confident, when a narrative fits too well — and holds these as warning signs rather than reassurance.

Contrasts with the default mode where uncertainty feels like threat: the threat response triggers [[narrative-filling]] (produce a story to close the void) and [[drunkard-under-streetlight]] (search where we already have tools). Uncertainty literacy interrupts that reflex and keeps the void open long enough for a real answer to arrive.
