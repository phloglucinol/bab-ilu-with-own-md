摘要：准确预测分子性质对于许多化学领域的计算设计至关重要。深度学习已被用于预测各种分子性质，而易于使用的开源软件的出现使得这些方法得以普及。Chemprop 是该领域最受欢迎的软件之一。它实现了定向消息传递神经网络 (D-MPNN) 架构，可以直接从分子图进行端到端学习，无需手动构建描述符或指纹。最初的 Chemprop 版本主要通过命令行界面使用，而不是通过 Python API 进行编程使用。随着该领域的不断发展，对基于 Python 的工作流程的模块化和可用性提出了更高的要求。作者对 Chemprop 进行了彻底重写，以满足这一需求，并在速度、可扩展性和整体用户体验方面进行了改进。作者进行了广泛的基准测试，以证明其算法性能与原始实现相当，同时执行时间缩短了约 2 倍，内存使用量减少了约 3 倍。Chemprop v2 可以有效地扩展到多个 GPU，从而能够训练更多更大规模的模型。Chemprop v2 还包含一些新功能。此外，作者还添加了丰富的 Jupyter Notebook 教程和所有主要功能的新文档。Chemprop v2 保留了其前身的预测精度，并增强了模块化、速度和可用性，使研究人员能够更有效地进行计算分子设计。
