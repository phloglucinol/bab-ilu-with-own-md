摘要：残基相互作用网络（RIN）模型是一种行之有效的方法，它基于蛋白质结构的接触拓扑特征，用于识别不同蛋白质结构中的功能残基和配体结合位点。在此，作者推出 RinPy——一个可通过 pip 安装的 Python 软件包，并提供一个基于 RIN 模型的图形用户界面（GUI）。RinPy 旨在构建、可视化并分析针对单个或多个蛋白质输入结构（以及分子动力学轨迹）的 RIN；该工具支持计算残基的三种中心性指标，即度中心性、紧密度中心性和介数中心性。介数中心性得分最高的节点可用于预测潜在的变构位点；此外，图谱分析功能可识别连接相邻残基簇的“铰链”区域。该程序通过集成多进程模块进行了性能优化，从而能够高效地分析大型蛋白质结构，并支持用户自定义网络分析所需的各项参数。该软件包支持将核苷酸、辅因子、小分子、水分子及离子直接整合进网络分析流程中，这对深入理解蛋白质复合物内部的功能性相互作用具有极高的价值。该程序由众多功能模块组成，可生成多种类型的分析结果输出，其中包括交互式可视化图表，旨在协助用户更直观地解读分析结果。此外，该工具还提供网络比较分析功能，能够定量评估配体结合或基因突变等扰动因素如何改变蛋白质复合物的接触拓扑结构。作者以单体 KRAS 蛋白及 KRAS–SOS1 复合物数据集为案例，对 RinPy 进行了应用演示；结果充分展示了该工具在识别已知功能残基及变构位点残基方面的卓越能力，并突显了其在 RIN 构建与分析方面所具备的高速运算性能。RinPy 软件包兼容 Windows、macOS 和 Linux 等主流操作系统。RinPy 是一款开源 Python 软件包，已通过 Python 包索引（PyPI）发布，其包名为“rinpy”；该项目的源代码现已托管于 GitHub 平台供用户查阅。此外，RinPy 的图形用户界面（GUI）版本也已打包为独立的 Windows 可执行程序，供用户直接下载使用。
