# mp-weixin-qq-com-mzawmjy0odk3nw-2247486049-1-opencode-ai-web-ui

## Layer 1 — bold key sentences

- **OpenCode 有三种完整形态：桌面端、Web UI、终端 TUI，三种形态共享同一套会话和状态。**
- **Research + Plan + Annotate：在桌面端完成，利用原生批注功能直接在计划上做标注。**
- **Implement 监工：通过 Web UI 在手机上看进度、回复 AI 提问。**

## Layer 2 — bold fragments

- **多形态共享同一会话状态**
- **桌面适合规格批注**
- **手机适合实施监工**
- **工具形态直接影响流程坚持度**

## Layer 3 — one-sentence thesis

一个 AI 工具是否真正支持工作流，关键不在模型接入数量，而在它能不能把“思考、批注、执行、监工”放到各自最顺手的界面里。

## Concepts (tier_1_atoms)

- [[multi-surface-agent-workflow]]：同一 agent 工作流在不同设备表面连续展开。
- [[mobile-supervision-loop]]：实现阶段的核心交互不是写代码，而是低摩擦监工。
- [[tool-shape-enables-methodology]]：方法论能否长期执行，取决于工具是否降低了关键步骤的摩擦。
