## Restoration

If v2.0 fails and v1.4 must be restored:
```bash
cd "$BABILU_VAULT_PARENT"  # parent dir of your vault, e.g. ~/Documents/
mv Bab-ilu Bab-ilu-v2-attempt
tar -xzf "$BABILU_REPO/archive/v1.4-vault-20260417.tar.gz"  # set BABILU_REPO to your clone
```
Then checkout git state pre-v2-sprint1 branch.
